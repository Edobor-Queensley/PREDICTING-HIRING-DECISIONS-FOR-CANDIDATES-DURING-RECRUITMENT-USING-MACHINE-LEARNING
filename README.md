# This is an end-to-end classification project that applies data-driven modeling to support recruitment decision-making. Using a Kaggle dataset of 1,500 candidates with demographic, skill, and interview-related features, the project includes exploratory data analysis, feature scaling, class-imbalance handling, and feature selection to prepare the data for modeling. 
# Random Forest and K-Nearest Neighbors classifiers were trained and optimized, with the Random Forest model achieving the highest performance at 92% accuracy. The solution was further implemented in Azure Machine Learning Studio.
